## 2. Metodologia M2.2.1 — inspeção ZIP/apktool sem brute force

### 2.1. Regras

- **Só nomes provados:** shard só é verificado se seu nome literal aparece em (`a`) arquivo físico `*.shard` dentro do ZIP **ou** (`b`) string dentro do APK (`*.dex`, `*.so`, `*.json`, `*.xml`, `smali`) matching `*.shard`/`*.xpak`/`shard_cdn`/`cdni.meta`/`manifest.json`/`split_asset_pack`/`IWff`/`KAPIs`/`prod.cdni.callofduty.com`. Qualquer nome não provado = não testado.
- **ZIP inspection leve:** `unzip -l warzone.xapk` lista entradas sem extrair; `apk-inspect.sh` resume `aapt dump badging` + `sha256` + `hasShard/hasManifest`; `shard-inventory.py` lista físicos `**/*.shard`; `shard-reference-scanner.py` grep lógico.
- **Sem volume:** para cada shard provado, só `curl -I` (HEAD) e `curl -H Range: bytes=0-1023 -D - -o /dev/null` (primeiro 1 KB). Nunca `GET` sem Range.
- **Sem auth:** `GET` anônimo, sem `Authorization`, sem token. Akamai responde 200 sem auth para manifests, espera-se mesmo para shards se ainda hospedados.

### 2.3. Como reproduzir quando APK chegar (preservação legal — externo, sem commit)

> **APK/XAPK real está só no S23 do usuário** (`/storage/emulated/0/Download/...`), não no workspace do agente. **Nunca** copie para `/home/user/Testtezt` (`.gitignore` + wrapper recusam). Use sempre caminho externo e `--out-dir` fora do repo. Só JSONs redigidos são compartilhados.

#### Opção A — wrapper único (recomendado, S23 Termux ou PC)

```bash
# S23 via Termux (APK já em Download, sem transferir):
bash warzone-offline/tools/asset-tools/run-external-apk.sh \
  --apk /storage/emulated/0/Download/warzone-3.10.0.19854920.xapk \
  --out-dir /storage/emulated/0/Download/wzm-out
# ou .apk:
bash warzone-offline/tools/asset-tools/run-external-apk.sh \
  --apk /storage/emulated/0/Download/base.apk \
  --out-dir /storage/emulated/0/Download/wzm-out --check-cdn

# PC após transferência temporária fora do repo (nunca dentro de Testtezt/):
adb pull /data/app/com.activision.callofduty.warzone-*/base.apk /tmp/wzm/warzone.apk
bash warzone-offline/tools/asset-tools/run-external-apk.sh \
  --apk /tmp/wzm/warzone.apk --out-dir /tmp/wzm/out --check-cdn

# Só ZIP list (sem extrair, mais leve):
bash warzone-offline/tools/asset-tools/run-external-apk.sh \
  --apk /storage/emulated/0/Download/warzone.xapk --out-dir /tmp/wzm/out --zip-only

# Saídas (fora do repo, compartilhe só os JSONs):
ls -lh /storage/emulated/0/Download/wzm-out/*.json
# apk-metadata.json (package/version/sha short/hasShard)
# physical-shards.json (path/size/sha16/header)
# shard-refs.json (provenShardNames + findings)
# shard-cdn.log (se --check-cdn, HEAD/Range por shard)
```

O wrapper valida: `--apk` **fora** do repo (`recusa` se dentro), `--out-dir` **fora** do repo, nunca escreve `*.apk/*.shard` em `Testtezt/`, e imprime instruções de compartilhamento.

#### Opção B — passos manuais (mesmo que wrapper, para debug)

